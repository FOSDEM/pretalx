# FOSDEM pretalx branch

This repository contains a fork of pretalx which is currently used for [FOSDEM](https://fosdem.org) and is running at [FOSDEM pretalx](https://pretalx.fosdem.org).

Our goal is making this repository obsolete as fast as possible by implementing our changes in [plugins](https://github.com/FOSDEM/pretalx-integration) or upstream contributions.

In the mean time, not that this branch is not useable without the plugins above, and any bug reports should be added under this [pretalx-integration](https://github.com/FOSDEM/pretalx-integration) repository.
